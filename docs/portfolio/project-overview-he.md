# Sikumon — סקירת פרויקט בעברית

## תיאור בשורה אחת

Sikumon היא אפליקציית Windows בעברית שמתמללת אודיו באופן מקומי והופכת את התמלול לסיכום, החלטות
ומשימות עם קישור מדויק למקור.

## תיאור למגייסים

Sikumon היא אפליקציית שולחן עבודה מלאה שתוכננה ונבנתה מקצה לקצה עבור משתמשים דוברי עברית.
האפליקציה מייבאת הקלטת פגישה, מבצעת תמלול מקומי ומציגה תמלול RTL ניתן לעריכה עם חותמות זמן,
העתקה וייצוא ל־TXT או SRT. ניתוח AI אופציונלי מקבל רק טקסט הקשור לתמלול ומחזיר סיכום, החלטות
ומשימות בעברית, עם הפניה לקטעי התמלול התומכים בכל תוצאה. המוצר מופץ כמתקין Windows עצמאי
וכולל שמירה מקומית, הגנת מפתח API, מנגנוני התאוששות ובדיקות אוטומטיות.

## תיאור טכני

האפליקציה מבוססת Python 3.12 ו־PySide6. התמלול המקומי משתמש ב־faster-whisper, במודל Ivrit.ai
בפורמט CTranslate2 ובחישוב CPU int8. בגרסה 0.1.0 הושמט במכוון זיהוי והפרדה בין דוברים, כדי
לשמור על תמלול מקומי קל יחסית ולאפשר תאימות למגוון רחב יותר של מחשבי Windows, לרבות מערכות
המבוססות על CPU בלבד. נתוני פגישות, מקטעים, גרסאות תמלול, ניתוחים וקישורי ראיות נשמרים
ב־SQLite באמצעות SQLAlchemy וטרנזקציות. OpenAI Responses API מחזיר Structured Outputs שנבדקים
באמצעות Pydantic; מזהי הראיות נבדקים מול גרסת התמלול המדויקת לפני השמירה. המפתח נשמר באמצעות
keyring ב־Windows Credential Manager. ההפצה נבנית עם PyInstaller ו־Inno Setup.

## תיאור עסקי/ללקוח

Sikumon מאפשרת לאנשי מקצוע דוברי עברית להפוך פגישות מוקלטות למסמך עבודה ברור וניתן לאימות,
מבלי להעלות את האודיו לשירות AI. ההקלטה והתמלול נשארים במחשב, והמשתמש מחליט אם לבקש ניתוח
ענן. התוצאה כוללת תמלול עריך, סיכום קצר, החלטות, משימות ומקור מדויק לכל פריט — פתרון מתאים
ליועצים, צוותים קטנים, ראיונות ופגישות לקוח.

סיימתי לבנות את Sikumon — אפליקציית Windows בעברית לניהול תוצרי פגישות, שתוכננה ונבנתה מקצה
לקצה.

האפליקציה מייבאת אודיו בעברית, מבצעת תמלול מקומי ומציגה תמלול עריך עם חותמות זמן, העתקה וייצוא
ל־TXT/SRT. רק כאשר המשתמש מבקש ניתוח, טקסט הקשור לתמלול נשלח ל־OpenAI; התוצאה היא סיכום,
החלטות ומשימות בעברית עם קישור לראיות המדויקות בתמלול.

SQLite/SQLAlchemy, Structured Outputs עם Pydantic, Windows Credential Manager, PyInstaller
ו־Inno Setup. במסגרת העבודה טיפלתי גם בטרנזקציות, התאוששות מתקלות, גרסאות תמלול, פעולות רקע,
אריזת DLL ב־Windows ובדיקות של היישום המותקן.

Sikumon זמינה כעת כגרסת פורטפוליו עם מתקין Windows עצמאי.
