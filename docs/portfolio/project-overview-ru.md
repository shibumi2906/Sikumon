# Sikumon — обзор проекта на русском

## Описание в одной строке

Sikumon — Windows-приложение для встреч на иврите: оно локально расшифровывает аудио и создаёт
саммари, решения и задачи с точными ссылками на исходные сегменты транскрипта.

## Описание для рекрутера

Sikumon — полноценный настольный продукт для ивритоязычных пользователей, спроектированный и
реализованный от начала до конца. Приложение импортирует запись встречи, локально распознаёт речь
и показывает редактируемый RTL-транскрипт с таймкодами, копированием и экспортом TXT/SRT.
Опциональный анализ OpenAI получает только связанный с транскриптом текст и возвращает саммари,
решения и задачи на иврите со ссылками на подтверждающие сегменты. Продукт поставляется как
самостоятельный Windows-инсталлятор и включает локальное хранение, защиту ключа, восстановление
после сбоев и автоматические проверки качества.

## Техническое описание

Приложение написано на Python 3.12 и PySide6. Локальный STT использует faster-whisper, модель
Ivrit.ai в формате CTranslate2 и CPU int8. SQLAlchemy транзакционно хранит в SQLite встречи,
сегменты, ревизии транскриптов, результаты анализа, доказательства и статусы операций. Structured
Outputs из OpenAI Responses API разбираются строгими Pydantic-моделями; идентификаторы
доказательств проверяются по конкретной ревизии транскрипта до коммита результата. API-ключ
хранится через keyring в Windows Credential Manager. Сборка и инсталлятор создаются PyInstaller
и Inno Setup.

## Описание для бизнеса/клиента

Sikumon помогает специалистам, работающим на иврите, превращать записи встреч в понятные и
проверяемые рабочие материалы без отправки аудио в AI-сервис. Запись и распознавание остаются на
компьютере пользователя, а облачный анализ запускается только по его выбору. На выходе доступны
редактируемый транскрипт, краткое саммари, решения, задачи и точный источник каждого пункта.

диагностика Windows DLL и проверка установленной сборки.
